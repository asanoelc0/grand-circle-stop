# grand-circle-stop — 旅費精算帳

スマホで使う旅行費用の精算アプリです。ビルド不要の静的ファイル (`index.html`) だけで動きます。

## できること

- 費用を **ホテル / ツアー / 移動 / 現地** の4分類で記録 (名称・金額・通貨)
- 割り勘: 支払い者を選び、参加者ごとの個人金額を「均等」または「個別に入力」で設定
- 通貨レートは **旅行開始日のレートで固定**。設定画面の「開始日のレートを取得」で
  frankfurter.dev (欧州中央銀行の参照レート) から取得、または手入力
- 精算画面: 誰が誰にいくら払えばよいか、メンバー別の立替/負担、カテゴリ別合計
- 入力内容は端末のブラウザ (localStorage) に自動保存し、次回起動時に復元
- バックアップ: 設定画面からデータをコピー / 貼り付けで復元

## 使い方

GitHub Pages などの HTTPS で公開し、スマホのブラウザで開いて「ホーム画面に追加」すると
アプリのように起動できます (Service Worker によりオフラインでも起動)。

ローカルで試す場合:

```sh
python3 -m http.server 8000
# http://localhost:8000 を開く
```
