# 旅行持ち物タグ仕分けアプリ

`index.html` をブラウザで開くだけで動く単一ファイルのアプリです（ビルド・サーバー不要）。
画面中央の持ち物リストに、画面下部のタグをドラッグ＆ドロップして仕分けします。

## 画面構成

- **中央**：仕分け対象のアイテムリスト（旅行の持ち物 24 件を初期登録済み）
- **下部**：タググループ（持っていく／現地調達・個数・ジャンル）とゴミ箱アイコン
- **上部**：アイテム追加フォームと、タグ別の絞り込みフィルタ

## 操作方法

| やりたいこと | 操作 |
| --- | --- |
| タグを付ける | 下部のタグをアイテムカードへドラッグ＆ドロップ |
| タグを外す | アイテム上のタグの「×」をクリック、または同じタグを再度ドロップ |
| 個数を決める | 「1個/2個/3個/5個」をドロップで設定、「＋1 / −1」で増減 |
| アイテムを削除 | アイテム左の ⠿ をゴミ箱へドラッグ、またはゴミ箱アイコンをアイテムへドラッグ |
| アイテムを追加 | 画面右上の入力欄に入力して「追加」 |
| 絞り込み | 上部のフィルタボタン（タグ別・未分類） |
| タッチ操作 | タグをタップして選択 → アイテムをタップで適用（ドラッグの代替） |

## タググループが混ざらない仕組み

タグは 3 つのグループに分かれ、**グループごとに独立して 1 つだけ**保持されます。

| グループ | 種別 | 動作 |
| --- | --- | --- |
| 持っていく／現地調達 | 排他選択 | 一方をドロップするともう一方は自動的に外れる |
| 個数 | 数値 | 設定タグは上書き、＋1/−1 は増減（0 未満にならない） |
| ジャンル | 排他選択 | 水・食料／機内グッズ／衣服／洗面・衛生／電子機器／書類・貴重品／医薬品／その他 から 1 つ |

内部的にはアイテムが `{ method, qty, genre }` という独立したフィールドを持ち、
ドロップされたタグは自分のグループのフィールドだけを書き換えます。
そのため「持っていく」と「衣服」のような別グループの選択肢は同時に保持され、
同じグループの選択肢が混在することはありません。

## 技術メモ

- 依存ライブラリなしの HTML / CSS / JavaScript 単一ファイル
- ドラッグは Pointer Events で実装しており、マウスとタッチの両方で同じ操作が可能
- 状態は `localStorage`（キー: `travel-packing-tagger/v1`）に自動保存。「初期化」で初期状態に戻ります
