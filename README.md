# grand-circle-stop

旅行用の持ち物リストアプリのための、バッグ選択ボタン用イラスト（SVG アイコン）。

「旅行前の部屋でスーツケースやカバンを広げている」イメージの UI を想定し、
バッグを押すとその中に入れるものリストが開く、という流れのデモを同梱しています。

## アイコン

簡略化したピクトグラムではなく、**実物の寸法比をそのまま持ったイラスト**にしています。
`viewBox` は「1cm = 4 units」の共通スケールで切ってあるので、同じ倍率で並べるだけで実寸比になります。

| ファイル | 内容 | 想定実寸 | viewBox |
| --- | --- | --- | --- |
| `assets/icons/suitcase.svg` | キャリーケース（中型・伸縮ハンドル／4輪スピナー／TSAロック／ネームタグ） | 45 × 70 cm | `0 0 180 280` |
| `assets/icons/backpack.svg` | リュックサック（25L 級デイパック・トップリッド／前ポケット／肩ベルト／コンプレッションストラップ） | 32 × 50 cm | `0 0 128 200` |
| `assets/icons/shoulder-bag.svg` | ショルダーバッグ（小ぶり・長さ調整金具付きストラップ／フラップ／クラスプ） | 27 × 19 cm（＋ストラップ） | `0 0 120 168` |

- 線幅・角丸・配色トーンを揃えているので、同倍率で並べても同一シリーズとして見えます。
- `<title>` / `<desc>` 付き。インライン展開すればそのまま読み上げに対応します。

### 実寸比で並べる

CSS 変数 `--cm` に「1cm あたりの px」を入れ、各アイコンの高さを cm 単位で指定します。

```css
:root{ --cm: 2.2px; }
.bag-btn[data-bag="suitcase"] svg{ height: calc(70 * var(--cm)); }  /* 154px */
.bag-btn[data-bag="backpack"] svg{ height: calc(50 * var(--cm)); }  /* 110px */
.bag-btn[data-bag="shoulder"] svg{ height: calc(42 * var(--cm)); }  /*  92px */
```

`--cm` ひとつで全体を拡大縮小できます（狭い画面では `1.7px` に落としています）。
一番小さいショルダーバッグでもボタン自体は十分な面積を持つよう、アイコンは
「棚（`.shelf`）」の中で床のラインに接地させ、タップ領域はカード全体にしてあります。

### 色のカスタマイズ

| 変数 | 用途 |
| --- | --- |
| `--bag-ink` | 輪郭線 |
| `--bag-base` | 本体のベースカラー |
| `--bag-shade` | 影・フラップ・マチなどの濃い面 |
| `--bag-accent` | ポケットやタグなどの差し色 |
| `--bag-metal` | 金具・バックル・キャスター |

```css
.bag-btn[aria-expanded="true"] svg { --bag-base:#2f7f8f; --bag-shade:#24606c; }
```

CSS 変数はインライン SVG でのみ効くため、`<img src="...">` ではなく
SVG を HTML に展開して使ってください（`index.html` は `fetch` で展開しています）。

## 配置の考え方

使用頻度に合わせて 2 段構成にしています。

- **主役（上段・横並びの大きいカード）**：キャリーケースとショルダーバッグ。
  旅行中いちばん触る 2 つなので、実寸比のまま大きく見せています。
- **サブ（下段・横長の点線カード）**：リュックサック。
  「観光先に合わせて出し入れする」役割なので一段下げつつ、
  幅いっぱいの横長ボタンにして押しやすさは落とさない形にしています。

## デモ

`index.html` が 3 つのボタンと、押したときに開く持ち物リストの動きを確認できるページです。
`fetch` を使うので、ローカルでは簡易サーバー経由で開いてください。

```sh
npx http-server -p 8123 .
# → http://127.0.0.1:8123/index.html
```

ライト／ダークどちらの配色にも対応しています。
