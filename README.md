# grand-circle-stop

旅行用の持ち物リストアプリのための、バッグ選択ボタン用イラスト（SVG アイコン）。

「旅行前の部屋でスーツケースやカバンを広げている」イメージの UI を想定し、
バッグを押すとその中に入れるものリストが開く、という流れのデモを同梱しています。

## アイコン

| ファイル | 内容 |
| --- | --- |
| `assets/icons/suitcase.svg` | キャリーケース（伸縮ハンドル・キャスター・ネームタグ付き） |
| `assets/icons/backpack.svg` | リュックサック（トップハンドル・バックル・前ポケット） |
| `assets/icons/shoulder-bag.svg` | ショルダーバッグ（長いストラップ・フラップ・バックル） |

- すべて `viewBox="0 0 128 128"` の正方形で、線の太さ・角の丸み・配色トーンを揃えた同一シリーズです。
- `<title>` / `<desc>` を持たせているので、インライン展開すればそのまま読み上げ対応になります。

### 色のカスタマイズ

各アイコンは CSS 変数で塗りを差し替えられます（未指定時は既定色にフォールバック）。

| 変数 | 用途 |
| --- | --- |
| `--bag-ink` | 輪郭線 |
| `--bag-base` | 本体のベースカラー |
| `--bag-shade` | 影・フラップなどの濃い面 |
| `--bag-accent` | ポケットやタグなどの差し色 |
| `--bag-metal` | 金具・バックル |

```css
.bag-btn.is-selected svg { --bag-base: #2f7f8f; --bag-shade: #24606c; }
```

CSS 変数はインライン SVG でのみ効くため、`<img src="...">` ではなく
SVG を HTML に展開して使ってください（`index.html` は `fetch` で展開しています）。

## デモ

`index.html` が 3 つのボタンと、押したときに開く持ち物リストの動きを確認できるページです。
`fetch` を使うので、ローカルでは簡易サーバー経由で開いてください。

```sh
npx http-server -p 8123 .
# → http://127.0.0.1:8123/index.html
```

ライト／ダークどちらの配色にも対応しています。
