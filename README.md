# grand-circle-stop

旅行用の持ち物チェックリスト。`index.html` をブラウザで開くだけで使えます（ビルド・サーバー不要）。

## できること

- **入れ物ごとにリストを分ける** — スーツケース、機内持ち込みバッグなど、入れ物を自由に追加・リネーム・削除できます。持ち物は入れ物の間で移動できます。
- **ジャンルをタグで管理** — 衣類 / 洗面・衛生 / 電子機器 / 書類・貴重品 / 医薬品 / 食品 / その他 を初期搭載。色付きのタグを自分で追加でき、1つの持ち物に複数のタグを付けられます。
- **タグで絞り込み・名前で検索** — 複数タグを選ぶと、すべてを含む持ち物だけが表示されます。
- **進捗表示** — 入れ物ごと・全体のパッキング済み件数をバーで表示します。
- **自動保存** — 内容はブラウザの localStorage に保存されます。JSON での書き出し／読み込みにも対応しているので、端末をまたぐ持ち運びやテンプレートの使い回しができます。

## 使い方

`index.html` をブラウザで開きます。

```
open index.html      # macOS
xdg-open index.html  # Linux
```
